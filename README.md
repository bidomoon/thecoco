# THE COCO · 더코코

SOKFARM 코코넛 꽃 수액 음료 330ml 사각팩을 국내에 소개하는 반응형 브랜드 홈페이지입니다.

## 현재 구성 · v12

1. 사각팩 목업이 중심인 메인과 음료의 세 가지 특징
2. 꽃 수액 원료 이야기와 실제 현지 수확 사진
3. 음료 한 제품의 원료·용량·제조 방식·활용법과 상세보기
4. 헬스장·골프장·거실·아기와 함께하는 네 장면
5. 제공 레시피 포스터와 네 가지 음료 레시피
6. 음료의 영양·음용·보관 가이드와 FAQ
7. SOKFARM 홍보 영상 전체와 공식 사이트 링크
8. 카페·호텔·리테일을 위한 음료 활용 제안

2026-10-15 사용자 결정에 따라 국내 소개·판매 제품을 이 음료 한 종류로 정리했습니다. 다른 제품의 카드·상세 데이터·분류·활용 탭·문구·이미지는 게시 폴더에서 제거했습니다. 제조사 홍보 영상과 제조사 외부 사이트는 원본을 유지합니다.

## 실행과 배포

`dist`를 게시하며 별도의 빌드나 서버가 필요하지 않습니다. 추가 레이아웃은 `dist/single-product.css`에 있습니다. Netlify `netlify.toml`의 게시 폴더 역시 `dist`이며 `.netlify` 운영 정보는 Git에서 제외합니다.

기존 검토용 `noindex` 설정을 유지합니다. 가격·판매 구성·한글 라벨·정식 판매 정보가 확정되면 업데이트합니다.

## 구매와 문의 연결

`dist/config.js`의 `shopUrl`, `productUrls.nectar`, `contactUrl`에 실제 HTTPS 주소를 지정합니다. 비어 있으면 준비 중 안내를 표시합니다. 비밀번호나 비밀키를 넣지 않습니다.

## 사진과 폰트

330ml 사각팩은 사용자 제공 도안을 바탕으로 만든 목업입니다. 생활 사진은 AI 연출이며 실제 고객·장소·제휴를 뜻하지 않습니다. 사진과 제조사 자료는 `asset-sources.json`, 홍보 문구 근거는 `marketing-evidence.md`에 기록했습니다.

Noto Sans CJK KR와 Noto Serif KR 400 웨이트의 로컬 v12 서브셋을 사용하며, OFL 라이선스는 `dist/assets`에 포함합니다.

## 확인

`qa/verify-v12.cjs`는 6개 화면 크기, 단일 제품 구성, 이미지 로드, 상세·스토어 안내, 레시피, FAQ, 영상 실제 재생, 모바일 메뉴 및 오류 여부를 확인합니다. `THECOCO_QA_LIVE=1`로 공개 사이트를 확인합니다. QA의 Chromium 경로는 실행 환경에 맞춰 지정합니다.
