# THE COCO · 더코코

프리미엄 코코넛 블라썸 컬렉션을 소개하는 반응형 브랜드 홈페이지입니다.

## 구성

- 실제 수액 음료 한 병과 밝은 음용 연출 사진을 크게 보여주는 첫 화면
- 음료 → 시럽 → 설탕 → 발효소스의 컬렉션, 용도별 필터
- 제품별 원료·형태·특징·활용법과 상세보기, 명확한 카드 버튼
- 실제 제품 사진을 포함한 활용 탭, 영양·보관 FAQ로 바로 이동하는 가이드
- 음료·홈카페·베이킹·식탁의 활용 사진과 설명
- 원료·영양·보관 가이드, 자주 묻는 질문
- 원료 채취 이야기와 별도 유통·납품 동선
- 카페24 연결을 위한 공식 스토어 버튼과 모바일 메뉴

## 디자인 방향

Califia Farms의 큰 제품 사진과 제품군별 색상, Big Tree Farms의 원료·활용·B2B 구조, AG1의 제품 선택 정보와 FAQ 구성을 참고했습니다. 다른 브랜드의 화면·문구·사진을 복제하지 않습니다.
아이보리·크림과 깊은 그린을 바탕으로, 제품별 색감을 절제해서 구분합니다. v7에서는 제목용 명조 서체, 비대칭 사진 프레임, 제품 번호, 얇은 구분선, 간결한 활용 탭과 납품 문의 영역을 적용했습니다. 추가 스타일은 `dist/premium.css`에서 관리합니다.
감량 효과나 제로 칼로리를 주장하지 않으며, 국내 영양표시·가격·정식 판매 구성이 확정되면 공식 스토어에 연결합니다.

## Netlify

`netlify.toml`의 게시 폴더는 `dist`입니다. 별도 빌드 명령이나 서버가 필요하지 않습니다.
운영 연결 정보는 `.netlify`에 저장되며 Git에 포함하지 않습니다.

## 카페24 및 문의 연결

`dist/config.js`의 `shopUrl`에 공식 쇼핑몰 HTTPS 주소를 넣습니다.
제품별 주소는 `productUrls`, 문의 페이지는 `contactUrl`에 지정합니다.
주소가 비어 있으면 준비 중 안내를 표시합니다.
API 키, 비밀번호 등 인증 정보는 이 파일에 넣지 않습니다.

## 운영 자료

회사 정보와 국내 판매 구성은 확정 자료에 맞춰 반영합니다.
현재 검토용 버전에는 검색 노출을 막는 `noindex`가 적용돼 있습니다.
공식 운영 정보 확정 후 HTML과 Netlify 헤더에서 제거합니다.

## 사진과 폰트

생활 장면은 AI로 제작한 연출 이미지이며 실제 제휴나 고객을 나타내지 않습니다.
제품·농장 사진의 출처는 `asset-sources.json`에 기록했습니다.
폰트는 Noto Sans CJK KR 사용 글자 서브셋이며 OFL 라이선스는 `dist/assets/OFL.txt`에 있습니다.

제목 서체는 Noto Serif KR의 400 웨이트를 로컬에서 서브셋한 CocoEditorial입니다. 라이선스는 `dist/assets/CocoEditorial-OFL.txt`에 있으며, 폰트는 외부 요청 없이 제공합니다.
